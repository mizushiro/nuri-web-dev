탭 컴포넌트 (UX.Tab) & 플레이어 연동 가이드

기상청 날씨누리 2026 표준 탭 컴포넌트의 사용법입니다. 다중 패널 전환 방식뿐만 아니라, 단일 패널에서 정보만 콜백으로 갱신하는 singlePanel 모드, 하위 탭이 포함되었을 때 인덱스가 섞이지 않는 중첩 탭 계층 격리, 그리고 레이더 영상 플레이어 연동 표준 가이드를 제공합니다.

1. 단일 패널 (콜백 전용) 탭 singlePanel: true

패널을 여러 개 만들지 않고, 단 1개의 패널 컨테이너만 유지한 상태에서 탭 선택 시 콜백 함수를 실행하여 내부 차트, 데이터, 텍스트만 비동기/동적으로 교체하는 모드입니다.
불필요한 id, aria-controls, aria-labelledby, aria-expanded 토글을 거치지 않아 성능과 접근성이 향상됩니다.

💡 적용 대상

분포도 탭(강수가능성/하늘상태/기온 등), 단일 차트 뷰어, 지도 필터 탭 등 패널 형태는 하나이고 내용값만 바뀌는 영역

✨ 핵심 장점

패널 DOM이 hide/show 되지 않아 깜빡임 없음, 콜백 함수 인자로 선택된 { index, n, tab, data }가 직관적으로 전달됨

⚡ 활성화 옵션

singlePanel: true 또는 renderMode: "callback" 설정으로 즉시 적용

라이브 데모 (탭을 클릭해 보세요) 실시간 인터랙티브 동작 중

강수가능성 데이터 뷰어

선택 번호: 1
[강수가능성] 24일(화)~25일(수) 중부지방을 중심으로 30~60% 강수 확률이 예측됩니다. 
<!-- 탭 버튼 영역 (data-tab-style로 원하는 디자인 선택) -->
<div data-tab="subtab2" data-tab-style="text_|_text">
  <div role="tablist">
    <button type="button" role="tab"><span>강수가능성</span></button>
    <button type="button" role="tab"><span>하늘상태</span></button>
    <button type="button" role="tab"><span>기온</span></button>
    <button type="button" role="tab"><span>최고기온</span></button>
    <button type="button" role="tab"><span>최저기온</span></button>
  </div>
</div>

<!-- 단 1개의 패널만 두어 계속 열려있는 상태로 유지 -->
<div data-tab-wrap="subtab2">
  <section role="tabpanel">
    <h2 class="sr-only">분포도 상세 내용</h2>
    <!-- 이 영역 내부의 데이터가 콜백에 의해 갱신됩니다 -->
    <div id="distribution-content">...</div>
  </section>
</div>
import { UX } from './resources/js-2026/ui-common.js';

// subtab2 단일 패널 콜백형 인스턴스 생성
UI.subtab2 = new UX.Tab({
  id: "subtab2",
  renderMode: "static",
  singlePanel: true, // 단일 패널(콜백 실행) 모드 필수 활성화
  selected: 1,         // 기본 선택 탭 (1번: 강수가능성)
  callback: (res) => {
    console.log("선택된 탭 정보:", res); // { index, n, tab, panel, data }
    switch (res.n) {
      case 1:
        console.log("1. 강수가능성 탭 실행");
        // 단일 패널 내부의 강수 데이터 또는 지도 레이어 갱신
        break;
      case 2:
        console.log("2. 하늘상태 탭 실행");
        break;
      case 3:
        console.log("3. 기온 탭 실행");
        break;
      case 4:
        console.log("4. 최고기온 탭 실행");
        break;
      case 5:
        console.log("5. 최저기온 탭 실행");
        break;
    }
  }
});

// 탭 초기화 실행
UI.subtab2.init();
2. 부모-자식 중첩 탭 (형제 단위 격리) Nested Isolation

부모 탭의 1번 패널 내부에 또 다른 하위 서브탭이 들어있는 다계층 구조입니다.
ui-tab.js 내부에서 panel.closest('[data-tab-wrap]') === this.#el_wrap 필터링을 거치므로 하위 탭의 패널이 부모 탭의 패널 인덱스에 섞여 들어가지 않고 완벽하게 형제 단위로 격리됩니다.

📌 중첩 탭 작성 규칙
부모 탭의 data-tab="parent"와 자식 탭의 data-tab="child" 이름(ID)은 반드시 서로 다르게 지정해야 합니다. 패널 래퍼(data-tab-wrap) 역시 동일한 이름으로 쌍을 맞춰줍니다.
중첩 탭 라이브 데모 (부모 탭 1, 2번을 눌러보세요) 형제 격리 동작 중

📁 부모 패널 1번 내부

자식 탭 [A]의 내용입니다. 부모 패널 1번 내부에서 안전하게 독립 토글됩니다.
자식 탭 [B]의 내용입니다. 부모의 다른 형제 패널과 인덱스가 절대 충돌하지 않습니다.

📁 부모 패널 2번 내용

부모 2번 탭의 독립된 내용입니다.

3. 기본 다중 패널 탭 renderMode: "static"

탭 버튼 N개와 패널 N개가 1:1로 매핑되어, 활성화된 탭에 대응하는 패널만 aria-expanded="true"로 노출되는 가장 일반적인 탭 방식입니다. 

<div data-tab="mainTab" data-tab-style="roundbox-small">
  <div role="tablist">
    <button type="button" role="tab"><span>기상전망</span></button>
    <button type="button" role="tab"><span>권역별 요약표</span></button>
  </div>
</div>

<div data-tab-wrap="mainTab">
  <section role="tabpanel">기상전망 내용</section>
  <section role="tabpanel">권역별 요약표 내용</section>
</div>
UI.mainTab = new UX.Tab({
  id: "mainTab",
  renderMode: "static",
  selected: 1,
  data: [
    { callback: () => console.log("1번 탭 오픈") },
    { callback: () => console.log("2번 탭 오픈") }
  ]
});
UI.mainTab.init();
4. 레이더 영상 플레이어 연동 #image-player-wrapper

5. Tab 컴포넌트 옵션 레퍼런스 Options & API

new UX.Tab(options) 생성자 및 인스턴스 메서드 규격입니다.

옵션명 타입 기본값 설명
id String 필수 탭 그룹 식별자. [data-tab="id"]와 [data-tab-wrap="id"]와 일치해야 함.
singlePanel Boolean false 단일 패널 모드 활성화. true 설정 시 패널 토글 없이 콜백 함수만 실행.
renderMode String "dynamic" "static" (기존 HTML 사용), "dynamic" (JS 자동 생성), "callback" (단일 패널형)
selected Number 1 초기 선택될 탭의 번호 (1부터 시작).
data Array [] 각 탭 아이템 설정 배열. { tab: '버튼명', callback: (res) => {}, src: '경로' }
scroll Boolean false 스크롤 연동 모드 활성화 (ScrollTrigger 연계).
scrollOffsetTop Number 120 스크롤 연동 시 상단 트리거 오프셋 픽셀값.

인스턴스 메서드 (Methods)

메서드 인자 설명
tab.init() - 탭 컴포넌트를 초기화하고 이벤트 리스너를 등록합니다.
tab.expanded(target) Number | String | Element 지정한 탭(인덱스 번호, ID 문자열, 엘리먼트 객체)을 프로그래밍 방식으로 활성화합니다.
tab.destroy() - 등록된 클릭 리스너, 키보드 네비게이터, 스크롤트리거를 해제하고 메모리를 정리합니다.
