기상청 레이더 영상 플레이어 (ImagePlayer) 가이드

기상청 날씨누리 레이더 영상(radar.do)의 지점별/합성 강수 영상, 재생 타임라인 슬라이더, 재생 속도/간격 조절, OpenLayers 기반 Kmap 연동 기능을 서브페이지나 단일 패널 탭 등에 안전하고 빠르게 이식하기 위한 표준 가이드입니다.

1. 실시간 인터랙티브 라이브 데모 Live Demonstration

현재 페이지에서 실제로 구동되고 있는 기상청 레이더 영상 플레이어입니다. 우측 상단의 [옵션보기] 스위치 토글, 재생/일시정지, 타임라인 클릭, 재생 속도 증감 버튼을 직접 테스트해 보세요.

▶ 타임라인 및 연속 재생

0.5초~2초 간격으로 시간대별 관측 레이더 이미지를 순차 로드하고 슬라이더 프로그레스 바와 동기화합니다.

🗺️ OpenLayers + Kmap 연동

기상청 전용 타일맵과 레이더 레이어를 OpenLayers 캔버스 위에 고해상도로 렌더링합니다.

⚙️ 반응형 옵션 패널

2. 마크업 구조 (HTML Architecture) DOM Tree & Selectors

ImagePlayer가 동작하기 위해 반드시 유지되어야 하는 3대 핵심 영역의 구조입니다.

💡 3대 영역 요약
1. 최상위 래퍼 (#image-player-wrapper): JS 인스턴스가 마운트될 부모 컨테이너
2. 옵션 컨트롤 폼 (.move-wrap[name="image-player-form"]): 영상/지점/시간 선택 셀렉트박스와 히든 설정값
3. 영상 뷰어 & 재생 컨트롤러 (.movi-img-area): 지도 캔버스가 그려지는 .movi-wrap과 재생 바 .control-movi-wrap

3. 필수 리소스 & 로드 순서 (Dependencies) Load Sequence

레이더 영상 플레이어는 OpenLayers 타일 매핑, 투영 변환(Proj4), Kmap 엔진, Vue 템플릿 컴파일러가 유기적으로 연결되어 동작하므로 스크립트 로드 순서가 매우 엄격합니다.

⚠️ 스크립트 로드 순서 위반 시 주요 오류
- OpenLayers is not defined: ol.bb.js가 kmap.bb.js보다 늦게 로드될 때 발생
- Vue is not defined: image-player.js 내부 범례 컴포넌트 마운트 실패
- window.wgisBaseUrl is undefined: 헤더의 전역 환경설정 객체 누락 시 지도 타일 404 발생

4. ImagePlayer 옵션 & 초기화 API Configuration API

new ImagePlayer(wrapperId, configUrl, options)에 전달할 수 있는 설정값과 파라미터 규격입니다.

옵션명 타입 기본값 기능 설명
type String "cmp" 레이더 합성모드("cmp": 전국 합성영상, "stn": 지점별 단독 관측소 영상)
showOptionControl Boolean true 옵션보기 토글 스위치 인터랙션 지원 여부
showOption Boolean false 최초 로드 시 옵션 선택창 열림 여부
timeTerm Number 5 재생 간격 (분 단위. 예: 5분, 15분, 30분, 60분)
interval Number 0.5 프레임 전환 속도(초). 0.5초마다 다음 관측 프레임으로 이동
autoStart Boolean false 페이지 진입 즉시 자동 연속 재생 시작 여부
kmapEnabled Boolean true OpenLayers/Kmap 지도 엔진 활성화
kmapOptions Object { zoom: 9 } 지도의 초기 줌 레벨(zoom), 위경도(lat, lon), 기본 줌(defaultZoom)
kmapLayers Array [{...}] 초기 로드할 레이어 설정. 예: [ { name: "radar", options: { type: "pop" } } ]
form.data.onchange Function callback 영상 셀렉트 변경 시(합성/지점/우박/눈비 등) 레이어 교체 및 줌 재조정 핸들러 
// 기본 레이더 합성영상 플레이어 인스턴스 생성 예시
var player = new ImagePlayer("image-player-wrapper", null, {
  type: "cmp",
  showOptionControl: true,
  showOption: false,
  timeTerm: 5,
  interval: 0.5,
  autoStart: false,
  kmapEnabled: true,
  kmapOptions: { zoom: 9, lat: 0, lon: 0, defaultZoom: 7 },
  kmapLayers: [
    { name: "radar", options: { type: "pop" } }
  ]
});
