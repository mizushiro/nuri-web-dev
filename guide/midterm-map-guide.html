중기예보 지도 & 타임라인 플레이어 가이드

기준시간(3시간, 6시간 등 가변 시간 범위)을 22칸으로 균등(1/n) 분할하여 분 단위 시점 이동, 실시간 파란 진행 바 채움 애니메이션, 파란 말풍선 툴팁 연동 및 자정 넘김 표기를 제공하는 표준 지도 플레이어 컴포넌트입니다.

22칸 1/n 동적 분할

총 기준시간 범위(기본 3시간)를 21개 균등 구간으로 나누어 22개의 시점을 분 단위까지 정밀하게 계산합니다.

▶

파란 진행 바 & 툴팁 연동

현재 재생 위치에 맞추어 흰색 트랙 위로 파란색 진행 바가 채워지며, 상단 말풍선이 1/n 비율로 부드럽게 실시간 이동합니다.

🌙

자정 넘김(자정 분기) 지원

23시~02시처럼 날짜가 바뀌는 시간대에는 11.24.(화) 23시 ~ 11.25(수) 02시와 같이 날짜와 요일이 자동으로 분기 표기됩니다.

⏱

3H / 6H 가변 범위 대응

3시간에 국한되지 않고 6시간, 12시간 등 다양한 예보 기준 시간에 맞춰 22칸이 가변 분할됩니다.

👆

모바일 터치 & 드래그 (스크러빙)

모바일 손가락 터치 및 드래그, PC 마우스 드래그를 통해 트랙 위를 스크러빙하며 원하는 예보 시점을 부드럽고 직관적으로 탐색할 수 있습니다.

JavaScript API 가이드 API REFERENCE

외부 컴포넌트나 비동기 데이터 갱신 시 전역 컨트롤러 객체인 window.nrMidtermPlayer 또는 모듈 인스턴스를 통해 제어할 수 있습니다.

메서드 (Method) 파라미터 (Parameters) 설명
goToStep(index) index: number (0 ~ 21) 지정한 눈금(0~21) 위치로 즉시 이동 및 진행 바/툴팁/텍스트 UI 동기화
setPlaying(boolean) playing: boolean 자동 순차 재생 시작(true) 또는 일시정지(false). 끝 도달 시 처음(0)부터 루프 재생
setDuration(hours) hours: number (예: 3, 6, 12) 시작 시간은 유지하고 기준 시간 간격(3시간, 6시간 등)을 변경 후 22칸 재계산
setStartDate(date, hours?) date: string|Date, hours?: number 기준 시작 일시 및 간격 변경 (예: 자정 넘김 테스트 등, 안전한 파싱 내장)
setRange(start, end) start: string|Date, end: string|Date 시작 일시와 종료 일시를 명시적으로 직접 지정하여 22칸 1/n 분할
getCurrentIndex() - 현재 선택된 스텝 인덱스(0~21) 반환
getInfo() - 현재 시점의 상세 정보 객체 반환 { tooltipText, rangeText }
destroy() - 재생 타이머(setInterval) 해제 및 드래그 상태 리셋 (탭 전환 시 메모리 누수 방지용)
📡 실시간 동기화 커스텀 이벤트: midtermPlayerChange

플레이어의 시점이 바뀔 때마다 window 객체로 midtermPlayerChange 이벤트가 자동 디스패치됩니다. 지도 레이어나 데이터 그리드 연동에 활용할 수 있습니다.

window.addEventListener('midtermPlayerChange', function (e) {
  var currentIndex = e.detail.currentIndex; // 0 ~ 21
  var totalSteps = e.detail.totalSteps;     // 22
  var tooltipText = e.detail.info.tooltipText; // '11/24.09:00'
  var rangeText = e.detail.info.rangeText;     // '11.24.(화) 09~12시'
});
JavaScript 제어 예시 
// 1. 6시간 기준 시간대로 변경 (09:00 ~ 15:00)
window.nrMidtermPlayer.setDuration(6);

// 2. 자정을 넘기는 시간대로 변경 (23:00 ~ 02:00)
window.nrMidtermPlayer.setStartDate('2026-11-24T23:00:00', 3);

// 3. 5번째 스텝으로 강제 이동
window.nrMidtermPlayer.goToStep(5);

// 4. 자동 재생 실행
window.nrMidtermPlayer.setPlaying(true);

// 5. 탭 종료 또는 페이지 언로드 시 타이머 해제
window.nrMidtermPlayer.destroy();
연동 & 보안 베스트 프랙티스 SECURITY & BEST PRACTICES

기상청 날씨누리 실제 시스템에 중기예보 플레이어를 탑재할 때 준수해야 할 메모리 관리, XSS 보안 대책, 지도 동기화 패턴 및 웹 접근성 가이드입니다.

🛡️ 1. XSS 방어 및 안전한 데이터 바인딩

외부 REST API로 받은 일시 문자열을 DOM에 렌더링할 때 innerHTML을 사용하지 않고 textContent를 통해 안전하게 바인딩합니다. parseSafeDate() 헬퍼가 내장되어 유효하지 않은 날짜 파라미터 유입 시 NaN 오류를 원천 차단합니다.

🧹 2. 탭 전환 시 생명주기 (메모리 누수 방지)

UX.Tab 연동 시 다른 서브탭(예: 3일~10일, 11일~30일 등)으로 전환되면 플레이어의 재생 타이머가 백그라운드에서 불필요하게 돌지 않도록 setPlaying(false) 또는 destroy()를 호출하여 타이머를 해제합니다.

🗺️ 3. 지도(OpenLayers / Kmap) 실시간 레이어 연동

midtermPlayerChange 이벤트를 구독하여 스텝 이동 시 지도 인스턴스의 타일 레이어나 WMS 시간 파라미터(TIME=...), GeoJSON 강수 확률 벡터 소스를 즉시 업데이트합니다.

♿ 4. WAI-ARIA & 키보드 접근성 준수

슬라이더 트랙에 role="slider", aria-valuenow, aria-valuetext가 실시간 연동되며, 키보드 방향키(좌/우/상/하 1스텝, Home 처음, End 끝, Space/Enter 재생 토글) 및 Focus 링 스타일이 지원됩니다.

⚠️ 개발자 보안 주의사항: 날짜 파라미터 유효성 검증

URL 쿼리스트링(?tm=...)이나 비동기 응답 데이터를 플레이어에 주입할 때, 반드시 ISO 8601 형식(YYYY-MM-DDTHH:mm:ss)을 준수하고, isNaN(new Date(...).getTime()) 여부를 사전 검증해야 날짜 연산 오류를 방지할 수 있습니다.

실제 서비스 연동 완결형 예제 (Tab + Map + Player Integration) 
<script type="module">
  import { initMidtermPlayer } from './resources/js-2026/component/ui-midterm-player.js';

  // 1. 플레이어 인스턴스 초기화
  const player = initMidtermPlayer({
    startDate: '2026-11-24T09:00:00',
    durationHours: 3 // 기본 3시간 (09~12시)
  });

  // 2. 플레이어 시점 이동 이벤트 수신 -> 지도 레이어 갱신
  window.addEventListener('midtermPlayerChange', (e) => {
    const { currentIndex, totalSteps, info } = e.detail;
    console.log(`[중기예보 시점 갱신] ${currentIndex}단계 / 시간: ${info.tooltipText}`);

    // [예시] 지도 라이브러리(Kmap / OpenLayers) 타일 또는 데이터 갱신
    if (window.kmapInstance && typeof window.kmapInstance.updateForecastLayer === 'function') {
      window.kmapInstance.updateForecastLayer({
        stepIndex: currentIndex,
        forecastTime: info.tooltipText
      });
    }
  });

  // 3. 표준 탭(UX.Tab)과 연동 시 생명주기 관리
  const forecastSubTab = new UX.Tab({
    id: 'tab-midterm-type',
    renderMode: 'static',
    selected: 1,
    callback: (v) => {
      // 탭 번호(v.n)에 따라 생명주기 제어
      if (v.n === 1) {
        // 중기예보 탭 활성화 시 UI 재정렬
        player.goToStep(0);
      } else {
        // 다른 탭으로 이동 시 백그라운드 재생 타이머 일시 정지 (메모리 절약)
        player.setPlaying(false);
      }
    }
  });
  forecastSubTab.init();
</script>
